# TC3 operator manual — service-menu facts (manual pp. 43–50, SD cab)

- Adjustment switches inside coin door: Service, Test (slide ON = test mode),
  Select Up/Down, Enter (p43).
- Test Mode: Test ON → MENU screen. Select Up/Down moves, Enter enters,
  EXIT in each test returns (p44).
- MENU items: COIN OPTIONS, GAME OPTIONS, I/O TEST, MONITOR TEST,
  SOUND TEST, BOOKKEEPING (ADS DATA), OTHERS. Bottom lines:
  LINK MALFUNCTION + number (1/2 = PCB fault incl I/O PCB, 3 = left/right
  software version mismatch), GAME DIFFICULTY L/R mismatch, dead batteries.
- I/O TEST: DIP, LINK ON 2, LINK AS 1 (LEFT); items I/O PCB CHECK,
  GUN INITIALIZE, SWITCH TEST, SOLENOID TEST (p47).
- GUN INITIALIZE: via menu, OR hold Service while turning Test ON (p48).
  Shoot screen → impact shown. Wrong → Service or Foot Pedal → cross screen:
  aim centre of cross + trigger, returns to check screen. Enter exits (p49).
- SWITCH TEST rows: credit count, SERVICE, TEST, UP/DOWN SELECT, ENTER,
  GUN TRIGGER, FOOT PEDAL; each flips OFF→ON live. Exit = Up Select +
  Enter together (p50).
- SOLENOID TEST: trigger fires solenoid (p51).
- OTHERS: ROM vers, CLOCK, S/N, LANGUAGE, CABINET LINKED, CDVD CHECK,
  BACKUP MEMORY INITIALIZE (YES wipes gun sights + hiscores — OFF LIMITS) (p54).
- GAME OPTIONS: LINK OFF/ON, LINK AS 1(LEFT), lives, difficulty, hit colour,
  HI-SCORE INIT (p46).
- Play: pedal DOWN = attack (can shoot, can be hit), pedal UP = hidden +
  reload. Demo clips skippable by aiming + shooting (p32).
